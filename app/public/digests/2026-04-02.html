TII Releases Falcon Perception: Compact 0.6B Vision Model Outperforms SAM 3 on Language-Guided Segmentation

The Technology Innovation Institute released Falcon Perception, a 0.6B-parameter early-fusion Transformer for open-vocabulary visual grounding and segmentation — the task of identifying and outlining objects described in natural language.

On the PBench benchmark, Falcon Perception beats Meta's SAM 3 by up to +21.9 points on spatial and relational queries, and +14.2 points on dense scenes with hundreds of objects. The release includes full model weights, a companion 0.3B Falcon OCR model, and a new diagnostic benchmark that separates visual understanding capabilities by complexity level.

"Beyond pass@1": New Framework Exposes Reliability Collapse in LLM Agents at Scale

A new reliability science framework reveals that capability rankings and reliability rankings diverge sharply as task complexity grows. Testing 10 models across nearly 24,000 episodes, software engineering success drops from 0.90 to 0.44 at long horizons. Four new metrics — Reliability Decay Curve, Variance Amplification Factor, Graceful Degradation Score, Meltdown Onset Point — give practitioners a rigorous production-readiness evaluation beyond single-attempt pass rates.

Cognitive Friction Framework Gives Tool-Using AI Agents a Principled "Stop Thinking" Signal

The Triadic Cognitive Architecture (TCA) addresses a common failure pattern in agentic AI systems: agents that query tools excessively, deliberate too long, or act erratically under ambiguous evidence. The decision-theoretic framework provides a formal stopping criterion grounded in expected utility rather than arbitrary token budgets, validated on two simulated environments — achieving 36 viability point gains in medical diagnostics and 33 integrity point improvements in network security triage.

Ablation studies show that jointly optimizing tool selection and stopping decisions is critical: stopping rules alone recover minimal benefit, making TCA relevant to any team running production agents with budget or latency constraints.
