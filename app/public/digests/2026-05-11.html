MachinaCheck: Multi-Agent CNC Manufacturability System Runs on AMD MI300X for Privacy

MachinaCheck emerged as a multi-agent AI system for CNC manufacturability analysis that runs entirely on-premise using AMD Instinct MI300X, addressing the critical confidentiality requirements of manufacturing customers who cannot send proprietary STEP geometry to commercial API endpoints. The system parses STEP files using cadquery for mathematically exact feature extraction, uses Qwen 2.5 7B running on AMD MI300X via vLLM for operations classification and feasibility decision-making, and produces complete manufacturability reports in 25 to 40 seconds end-to-end.

"Complete manufacturability reports in 25 to 40 seconds end-to-end — without a single byte of proprietary geometry leaving the factory floor."

The five-component pipeline uses LangChain and FastAPI, with pure Python components for STEP file parsing and tool matching where LLMs are not needed, and Qwen 2.5 7B for operations classification, feasibility decision-making, and report generation. The system runs entirely on-premise with 192GB of HBM3 VRAM and 5.3 TB/s of memory bandwidth — eliminating the commercial API dependency that has long blocked AI adoption in precision manufacturing.
