IBM Releases Granite 4.1: Dense Open-Source LLMs with 512K Context

IBM released Granite 4.1, a family of dense decoder-only LLMs (3B, 8B, and 30B) trained from scratch on approximately 15 trillion tokens using a five-phase pre-training pipeline. The models support up to 512K token context windows and are released under the Apache 2.0 license — notably, the 8B instruct model matches or surpasses the previous Granite 4.0-H-Small (32B MoE with 9B active parameters) across benchmarks including IFEval, AlpacaEval, MMLU-Pro, BBH, GSM8K, and code tasks.

AI Evaluation Becomes New Compute Bottleneck as Costs Skyrocket

AI evaluation has crossed a cost threshold that fundamentally changes who can participate in benchmarking frontier models. The Holistic Agent Leaderboard (HAL) spent approximately $40,000 to run 21,730 agent rollouts across 9 models and 9 benchmarks — a single GAIA run on a frontier model can cost $2,829 before caching, while PaperBench evaluations cost ~$9,500 per run including grading. Static benchmarks can compress 100–200× without losing rankings, but agent benchmarks compress only 2–3.5× at best, and training-in-the-loop benchmarks resist subsampling almost entirely.

Synthetic Computers at Scale Enable Long-Horizon Agent Training

Researchers introduced Synthetic Computers at Scale, a methodology for creating realistic synthetic computer environments with folder hierarchies and content-rich artifacts — documents, spreadsheets, presentations — to scale synthetic data creation for long-horizon productivity scenarios. Each simulation run requires over 8 hours of agent runtime and spans more than 2,000 turns on average, producing rich experiential learning signals validated by significant improvements on both in-domain and out-of-domain productivity evaluations.

Methodological Evolution Graph Maps AI Research Development

Researchers introduced Intern-Atlas, a methodological evolution graph built from 1,030,314 papers spanning AI conferences, journals, and ArXiv preprints — comprising 9,410,201 semantically typed edges, each grounded in verbatim source evidence, forming a queryable causal network of methodological development. The graph enables downstream applications in idea evaluation and automated idea generation, positioning methodological evolution graphs as a foundational data layer for automated scientific discovery.

Study Finds Sparse Autoencoders Suboptimally Recover Concept Manifolds

Researchers developed a theoretical framework analyzing how sparse autoencoders (SAEs) capture concept manifolds, finding that SAEs mix global subspace and local tiling solutions in a fragmented regime they call dilution — explaining why manifold structure is rarely visible at the level of individual concepts. The results suggest future representation learning methods should treat geometric objects, not just individual directions, as the basic units of interpretability.

Policy Gradient Penalty Achieves Global Optimality for Constrained Exploration

Researchers proposed Policy Gradient Penalty (PGP), a single-loop policy-space method that enforces general convex occupancy-measure constraints via quadratic-penalty regularization for constrained exploration in reinforcement learning. Leveraging hidden convexity and strong duality, they established global last-iterate convergence guarantees, attaining an ε-optimal constrained entropy value with ε-bounded constraint violation despite policy-induced non-convexity.

Efficient Dynamic Model Merging via Learnable Task Vector Compression

Researchers proposed T-Switch, which decomposes task vectors into three compact components — a binary sparse mask, a sign vector, and a scalar scaling factor — achieving high-fidelity approximation at high compression ratios. Building on this, they introduced Auto-FlexSwitch, a dynamic model merging approach incorporating a K-Nearest Neighbor inference scheme with a learnable low-rank metric that supports highly efficient task vector compression and automatically composes task vectors through feature similarity retrieval.
