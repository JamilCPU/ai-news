01  ·  Chart Generation

Validation-Driven LLM Workflow Generates 1,500 Statistical Charts with 30,000 QA Pairs

A structured LLM-based workflow decomposes chart generation into dataset screening, plot proposal, code synthesis, rendering, validation-driven refinement, and question-answer generation. Applied to UCI datasets, the workflow produces 1,500 charts from 74 datasets spanning 24 chart families — paired with 30,003 QA pairs. Evaluation of 16 multimodal LLMs shows chart-syntax questions are nearly saturated while value extraction, comparison, and reasoning remain challenging.

02  ·  Agent Execution

RunAgent Interprets Natural-Language Plans with Constraint-Guided Execution

RunAgent bridges the expressiveness of natural language with the determinism of programming via an agentic language with explicit control constructs (IF, GOTO, FORALL). It autonomously derives and validates constraints at each step, dynamically selecting among LLM reasoning, tool use, and Python code generation. Evaluations on Natural-plan and SciBench outperform baseline LLMs and state-of-the-art PlanGEN methods.

03  ·  Multi-Agent RL  ·  ICML 2026 Spotlight

NonZero Enables Tractable Multi-Agent MCTS via Interaction-Guided Exploration

NonZero keeps multi-agent Monte Carlo Tree Search tractable by running surrogate-guided selection over a low-dimensional nonlinear representation with an interaction-guided proposal rule, instead of exploring the full joint-action space. An interaction score ranks single-agent deviations by predicted gain and scores two-agent deviations via a mixed-difference measure. Empirically improves sample efficiency on MatGame, SMAC, and SMACv2 under matched search budgets.

04  ·  Topological Deep Learning

Combinatorial Complex Weisfeiler-Lehman Test Unifies Topological Deep Learning

The CCWL test extends the WL test to combinatorial complexes, unifying set-based and part-whole structures into a common topological framework through four types of neighborhood relation. Upper and lower neighborhoods alone are sufficient to reach the expressivity of the full CCWL framework. The Combinatorial Complex Isomorphism Network (CCIN) outperforms baselines on synthetic and real-world benchmarks.

Deep Kernel Learning Stratifies Glaucoma Trajectories by Risk Progression

A novel deep kernel learning architecture couples a Gaussian Process backend with a transformer-based feature extractor on clinical-BERT embeddings to model glaucoma patient trajectories from sparse EHR data. The method identifies three clinically distinct subgroups and, crucially, decouples disease progression from current severity — identifying a high-risk group with worsening trajectory despite better average visual acuity than a stably poor group.

06  ·  LLM Evaluation  ·  AAAI 2026

Obfuscated Natural Number Game Evaluates Architectural Reasoning in LLM Provers

The Obfuscated Natural Number Game benchmark evaluates Architectural Reasoning — synthesizing formal proofs using only local axioms in an alien math domain — by renaming Lean 4 identifiers to remove semantic cues. Results reveal a universal latency tax under obfuscation, and a divergence in robustness: general models (Claude Sonnet 4.5, GPT-4o) degrade, while reasoning models (DeepSeek-R1, GPT-5, DeepSeek-Prover-V2) maintain accuracy.

07  ·  Safe Reinforcement Learning

Augmented Lagrangian Multiplier Network Stabilizes State-wise Safety in RL

ALaM introduces a quadratic penalty into the augmented Lagrangian for local convexity near the optimum, and a multiplier network trained via supervised regression toward a dual target for stable convergence. Theory guarantees multiplier convergence and recovery of the optimal constrained policy. SAC-ALaM outperforms safe RL baselines in both safety and return while learning well-calibrated multipliers for risk identification.

LLM Fine-Tuning  ·  Memory Efficiency

AdaMeZO: Adam-Style Zeroth-Order Optimizer for LLM Fine-Tuning Without Maintaining Moments

AdaMeZO leverages Adam-style first- and second-moment estimates without storing them in memory, addressing MeZO's slow convergence while preserving its backpropagation-free memory advantage. Standard Adam triples memory requirements; AdaMeZO circumvents this through theoretical analysis and a novel estimation scheme. Experiments show AdaMeZO outperforms MeZO while requiring up to 70 percent fewer forward passes, with trajectory visualizations confirming its adaptation to diverse loss landscapes.
